# 花猫 Huamao

**爱花，也爱它。** 一个帮助养猫、养狗家庭查询植物资料、了解猫狗健康风险，并交流养护经验的微信原生小程序。

项目处于本地原型阶段，包含原生小程序和浏览器交互预览，尚未上线微信。项目代码提供 AGPL-3.0-only 开源许可及单独商业授权两条路径，不包含付费会员、商城或支付功能。

## 1. 项目要解决什么问题

养宠家庭买花、养盆栽时，常常不知道植物是否会影响猫狗健康；“百合”“菊花”等常用名又可能指向不同物种或园艺类群，不能简单地根据名字相似就判断安全。

花猫希望帮助用户：

- 通过中文名、常用名或学名找到植物档案，先辨别名称，再查看风险。
- 分别查看对猫、对狗的风险说明、防护建议和养护要求，并追溯依据来源。
- 收藏关心的植物，记录实际体验，在互助板块交流问题。

当前收录 **30 个分类档案**，覆盖常见鲜花与盆栽，包含物种、属级总览、杂交类群和栽培品种。档案数量不等于物种数量，也不是完整植物数据库。

## 2. 主要功能

底部导航为 **首页、植物图鉴、花友互助、我的**。

| 模块 | 已实现的功能 | 当前限制 |
| --- | --- | --- |
| 首页 | 植物名称搜索、拍照识别入口、收藏与账号入口 | 搜索使用本地收录的数据 |
| 植物图鉴 | 中文名、别名、学名检索；猫狗切换；风险筛选；按常用名或学名排序；歧义名称提示 | 搜索结果与名称候选不等于确认植物身份 |
| 植物详情 | 学名、科属、其他常用名、旧学名（如有）、特征、光照/浇水/环境要求；猫狗风险、防护建议、来源与证据范围、相近名称入口 | 资料尚待专业复核，图形符号不是植物实拍照片 |
| 植物收藏 | 收藏、取消收藏、仅查看已收藏植物 | 按账号保存在本机 |
| 铲屎官经验 | 在植物详情记录 10–1000 字经验，选择养护心得/隔离防护/接触经历和宠物类型，分类查看及删除；“我的”汇总查看 | 个人记录未经核实，不公开，不改变植物风险结论 |
| 我的 | 头像、昵称、养宠身份编辑；收藏与经验入口；隐私和来源说明；退出登录 | 默认使用本机体验账号，真实微信能力需部署 |
| 花猫成长册 | 每日打卡、主动标记已了解的植物档案、按不同植物的经验记录积累徽章 | 本机保存；徽章不是专业资质或可兑换积分 |
| 花友互助 | 养花求助、养宠防护、经验分享、闲聊日常；发帖、搜索、分类、详情和文字回复 | **仅当前账号在本机可见，尚不是跨用户公共论坛** |
| 拍照识别 | 原生小程序包含选图、授权说明、调用云函数、处理候选与未知结果的流程 | 默认未配置，不能离线识别；浏览器仅预览选图，不调用识别服务 |

### 养宠身份与成长徽章

养宠身份由用户主动选择，可随时修改：

| 养宠情况 | 身份称号 |
| --- | --- |
| 养猫 | 勤劳铲屎官 |
| 养狗 | 风雪遛狗人 |
| 猫狗都有 | 猫狗双全大赢家 |

成长徽章与身份称号分开展示：

- 认识植物：阅读详情与风险后，主动点击“已了解 · 记入成长册”；不同档案累计 3、10、20、30 份解锁徽章，重复确认不增加进度。
- 每日打卡：按北京时间每日一次，累计 3、7、30 天解锁。漏签不清空累计天数，连续天数单独计算。
- 记录经验：为 1、3、10 份不同植物档案保存至少 10 字的经验。相同植物多次记录只计一次，删除该植物的全部经验后重新计算进度。
- 互助回复：当前不计成长奖励，待公共问答、审核及有效帮助标准接通后再启用。

详细规则见 [成长册说明](docs/GROWTH.md)。

## 3. 安装与运行

### 环境要求

- 浏览器预览和自动测试：Node.js 18 或更高版本、npm。
- 启动本地预览服务器：Python 3，命令名为 `python3`。
- 原生小程序：微信开发者工具。

前端使用原生 WXML / WXSS / JavaScript；预览和测试使用 Node.js、Python 标准库，**本地体验不需要执行 `npm install`**。云函数另有依赖，仅在部署云服务时安装。

### 方式一：浏览器预览

下载项目后，在项目根目录打开终端：

```bash
npm run preview
```

该命令先同步植物数据、辨名和本地交互逻辑，再启动预览服务器。浏览器打开：

[http://127.0.0.1:8765/](http://127.0.0.1:8765/)

资料准备清单位于：

[http://127.0.0.1:8765/preparation.html](http://127.0.0.1:8765/preparation.html)

首次进入时，阅读本机体验说明，勾选后点击“创建 / 登录本机体验账号”。已有本机登录状态时直接进入首页。预览是浏览器页面，不代表微信真机运行结果。

保持终端运行即可使用；按 `Ctrl+C` 停止服务。若提示端口 8765 已占用，先检查是否已经启动了同一预览，避免重复启动。

修改共享数据或工具逻辑后，可执行：

```bash
npm run sync:preview
```

然后刷新浏览器。不要直接修改生成的 `preview/plants.js`。

### 方式二：微信开发者工具

1. 打开微信开发者工具，导入**项目根目录**，工具读取 `project.config.json`。
2. 项目默认配置 `appid: "touristappid"`，`miniprogram/config.js` 的 `cloudEnv` 为空，用于本机体验。云能力及正式发布需要自己的 AppID。
3. 编译运行，阅读说明并创建本机体验账号，即可使用名称搜索、详情、收藏、经验、成长册和本机互助帖子。
4. 未配置云环境时，照片识别会提示服务未配置，不会返回模拟结果。

浏览器的 localStorage 与微信设备存储相互独立，二者数据不会互通。当前尚未完成微信真机与云服务验收。

### 可选：接通微信账号与真实照片识别

这不是本地体验的前置条件。

1. 准备自己的微信小程序 AppID、云开发环境，填写 `project.config.json` 和 `miniprogram/config.js`。
2. 按 [账号部署说明](docs/ACCOUNT_SETUP.md) 创建 `users` 集合、配置访问权限并部署 `cloudfunctions/account`，部署时选择云端安装依赖。
3. 首次云端注册默认关闭。完成正式隐私说明、运营主体、保存期限及注销删除流程后，按账号文档更新政策版本并配置 `ACCEPT_REGISTRATIONS=true`。
4. 部署 `cloudfunctions/identify` 并云端安装依赖；在**云函数环境变量**配置 `BAIDU_API_KEY`、`BAIDU_SECRET_KEY`。不要把密钥放进前端或提交到仓库。
5. 识别依赖百度植物识别服务和已注册的微信身份。调用前确认第三方处理说明；支持 JPEG / PNG，传输的 base64 字符串上限为 4 MiB，过大需压缩。
6. 配置云端权限、限流、预算与告警，并完成真机测试后再考虑公开服务。

已有云函数代码不表示服务已部署。微信登录也不会自动把收藏、经验、成长或帖子上传到云端。公共论坛的数据库、审核和举报服务尚未实现，详见 [互助板块说明](docs/COMMUNITY.md)。

## 4. 使用方法

### 查询植物

1. 在首页输入植物中文名、别名或学名，进入图鉴。
2. 选择猫咪或狗狗，按需筛选风险、切换排序。
3. 如出现名称歧义提示，先比较学名、分类层级及植物特征，不直接采用其中某个结论。
4. 进入详情，阅读植物介绍、猫狗风险、防护建议、来源和证据范围。
5. 可收藏档案；阅读后主动记入成长册。需要记录实际观察时，在下方“铲屎官经验”填写内容。

未收录或未能确认身份的植物，不应当被视为安全。资料列为无毒也不代表可以食用，任何植物都可能引起猫狗肠胃不适。疑似误食或出现不适应及时联系兽医，勿等待社区答复。

### 我的与成长册

1. 进入“我的”，点击“编辑资料与身份”，设置昵称、主动选择头像及养宠称号，保存后生效。
2. 从收藏入口查看已收藏档案，从经验入口查看自己在不同植物下的记录。
3. 打开“花猫成长册”，每日打卡，查看各维度进度和徽章。
4. 退出登录仅结束当前客户端登录状态，不会删除本机资料。

默认体验账号不会获取真实微信身份或手机号。原生小程序的云端模式提供微信身份注册与独立手机号授权流程；头像、昵称由用户填写，手机号可不绑定，当前没有短信登录功能。

### 花友互助

1. 点击底部“花友互助”，按分类浏览或搜索帖子标题、正文。
2. 点击“发帖交流 / 提问”，选择分类，填写 4–60 字标题、10–2000 字正文。
3. 点击“保存帖子（仅本机）”，进入帖子详情；回复要求 5–1000 字。
4. 返回广场可保留当前帖子编辑草稿，但草稿仅在页面内存中，刷新或离开后可能丢失。

这是公益交流方向的本地原型。当前没有跨用户发帖、通知、举报处理、论坛帖子编辑/删除或公共内容审核功能；不要将本机保存理解为已向他人公开发布。

## 5. 输入输出示例

以下查询示例对应当前数据与界面标签，不代表对照片中植物的鉴定。

### 示例一：按学名查询

**输入：** 搜索 `Zantedeschia aethiopica`，选择“猫咪”。

**输出：** 找到“白花马蹄莲”，显示学名 `Zantedeschia aethiopica`、天南星科、`Zantedeschia` 属、常用名“马蹄莲、calla lily”，当前猫风险标签为“有毒 · 需要隔离”。进入详情可查看解释、养护与来源。

### 示例二：名称不明确或未收录

| 输入 | 当前输出 |
| --- | --- |
| 搜索 `香水百合` | 展示百合相关候选与名称歧义提示，提醒商品描述不能确认物种或安全；不会自动确认是哪一种百合 |
| 搜索 `不存在的植物` | 0 个结果；不生成虚构档案，不给出安全承诺 |
| 未配置云环境时，在原生小程序选择照片并开始识别 | 提示“识别服务尚未配置”，引导使用名称搜索 |

### 示例三：积累成长

**输入：** 在 3 份不同植物详情读完内容后，分别点击“已了解 · 记入成长册”。

**输出：** 成长册“认识的档案”为 3，解锁“初识花草”，下一枚“花间漫步”的进度为 `3 / 10`。再次确认同一档案不增加数量。

**输入：** 当日点击“今日打卡”。

**输出：** 显示“今日已打卡 ✓”，累计天数增加 1；同一天不能重复增加。

### 示例四：保存互助帖子与回复

**输入：**

```text
分类：养宠防护
标题：阳台植物如何隔离
正文：想交流一下有猫家庭阳台的日常植物隔离办法。
```

**输出：** 本机广场新增一篇帖子，展示当前账号昵称、日期和分类，初始回复数为 0。其他用户和设备看不到该帖子。

**回复输入：** `可以描述一下阳台的门窗情况。`

**输出：** 帖子详情新增该条本机回复，回复数变为 1。当前不因此获得问答成长奖励。

## 数据来源、隐私与发布边界

植物资料位于 `miniprogram/data/plants.js`，为原创中文摘要，每条附来源链接、依据对象、适用范围与复核状态。参考来源包含 ASPCA、FDA、Pet Poison Helpline、NC State Extension、RHS、Kew 和 NParks；不声称与这些机构官方合作。

当前全部 30 个档案已附毒性及养护参考，**完成兽医复核的档案为 0，有核实实拍照片的档案为 0**。有来源不等于经过专业签审。风险标签是产品展示分类，不是临床分级，用户经验不会覆盖文献结论。本工具不代替兽医诊断治疗。

本机资料按账号区分，浏览器清理数据、设备更换可能导致丢失；不是备份或云端同步。本地记录可以被修改，成长机制没有服务端防作弊保障。正式账号注销与服务端删除流程仍待完善。

上线前仍需完成真实微信部署与验收、专业内容复核、图片授权核实、正式隐私说明、云端存储与权限、社区审核举报和反垃圾等工作。详见：

## 开发与验证

在项目根目录执行：

```bash
npm test
npm run audit:data
npm run check:release-data
```

- `npm test`：运行搜索、名称歧义、资料结构、账号边界、个人经验、成长逻辑和本机论坛等自动测试。
- `npm run audit:data`：更新资料准备报告和预览进度文件。
- `npm run check:release-data`：资料发布检查。当前因缺少专业签审和照片记录而预期失败，不能靠编造审核记录绕过。

自动测试不等于微信真机、第三方识别或公共社区验收。

项目主要目录：

```text
miniprogram/      微信原生页面、共享数据与本地业务逻辑
cloudfunctions/  微信账号与百度植物识别云函数（需另行部署）
preview/         浏览器交互预览与资料准备清单
scripts/         数据同步和资料检查
tests/           自动测试
docs/            范围、资料规范、部署及功能边界说明
```
