# 花友互助

公益论坛取代原“花猫好物”入口，沿用原 shop 页面路径以兼容导航。

本地版支持分类浏览、搜索、新建帖子和文字回复。数据以账号专属 community 键保存，其他用户与设备不可见；没有示例用户或虚构帖子。标题 4–60 字、正文 10–2000 字、回复 5–1000 字。返回列表可保留当前编辑中的帖子草稿（内存，刷新或离开后可能丢失）。

当前不计入问答成长奖励，不提供交易、支付或广告服务。

公共上线仍需：云数据库与账号权限；服务端校验；内容安全审核；举报入口和处置后台；反垃圾与发布频率限制；作者编辑、删除及账号数据删除；隐私协议和运营联系方式。上线前，未经审核的内容不得直接公开。宠物急症不应等待论坛答复，用户经验不能改变植物风险标签。
