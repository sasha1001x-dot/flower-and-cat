# 花猫成长册（本地体验）

入口：“我的” → “花猫成长册”。成长徽章与养宠身份分开，参与进度不代表专业资质。

- 认识植物：在详情阅读介绍、风险和防护后，主动确认记入成长册。按不同档案 ID 去重，3 / 10 / 20 / 30 份档案解锁阶段徽章。含属级总览与品种，不宣称对应物种数；打开页面不会自动计数。
- 打卡：北京时间每日一次，累计 3 / 7 / 30 天解锁。漏签不清空累计天数，连续天数独立计算。
- 经验：按写过至少 10 字经验的不同植物档案计数，1 / 3 / 10 份解锁。删除对应全部经验会重新计算，重复发文不会刷进度。当前为未经审核的个人记录，不按医学正确性授予奖励。
- 问答：尚未实现，不计奖励。未来应建立内容审核、有效回答标准、有帮助反馈、防互刷和危险内容处理后再启用。

成长数据保存在账号专属的本机存储键中，不同步。现阶段可被用户本地修改，不具有权益或兑换价值。上线后迁移到服务器时间与事件去重校验，再考虑正式积分；不得让增长机制鼓励试吃、暴露宠物或无依据诊疗建议。
